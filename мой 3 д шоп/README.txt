PRINT LAB — сайт-витрина на HTML, CSS и JavaScript

КАК ОТКРЫТЬ
1. Распакуй архив.
2. Открой index.html в браузере или открой папку в VS Code и запусти через Live Server.

ВАЖНО ПРО TELEGRAM
В script.js найди:
const OWNER_TELEGRAM = "YOUR_TELEGRAM_USERNAME";
Замени YOUR_TELEGRAM_USERNAME на свой Telegram username без @.
Например: const OWNER_TELEGRAM = "my_print_lab";

Когда покупатель заполнит форму, сайт откроет чат с тобой и подготовит текст заказа.
Покупатель должен сам нажать «Отправить» в Telegram. Для полностью автоматической отправки через бота нужен отдельный сервер и настройка Telegram Bot API.

УПРАВЛЕНИЕ ТОВАРАМИ
Кнопка «Управление товарами» позволяет добавить фото, название, описание и цену. Можно загрузить фото с устройства.
Пока товары и раздел «Обо мне» сохраняются только в localStorage этого браузера и устройства. Другие посетители не увидят твои изменения. Для публичного магазина потребуется база данных и защищённая админ-панель.

ПЕРЕД ПУБЛИКАЦИЕЙ
- Замени демонстрационные товары, цены и фотографии на свои.
- Добавь свой Telegram username.
- Проверь все тексты и контакты.
- Не публикуй личный адрес или другие чувствительные данные.


АДМИН-ПАНЕЛЬ
1. Нажми «Управление товарами» на сайте.
2. В окне входа введи логин: admin
3. Пароль по умолчанию: PrintLab!2026
4. После входа можно добавлять товары и удалять их. Кнопка «Выйти» закрывает доступ к панели.
5. Перед публикацией измени ADMIN_PASSWORD в script.js на свой уникальный пароль.

ВАЖНО О ЗАЩИТЕ
Это только простая клиентская блокировка интерфейса. Пароль находится в JavaScript-файле и технически может быть найден посетителем, поэтому это НЕ настоящая защита для публичного магазина. Для реальной защиты нужна серверная авторизация и база данных. Данные товаров пока сохраняются только в браузере этого устройства.


УДАЛЕНИЕ ТОВАРА С ПАРОЛЕМ
Каждый раз при нажатии на крестик удаления товара открывается окно входа. Товар удалится только после правильного логина и пароля. Если закрыть окно или ввести неверные данные, товар останется.
Папка images обязательна и должна оставаться рядом с index.html.
